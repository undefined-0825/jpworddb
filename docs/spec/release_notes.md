# リリースノート

## Google Play 提出用

### version 1.0.1+2（初回リリース）

ことわざ・四字熟語をタップで完成させる和語パズル「コトノハ」の初回リリースです。

- ことわざ・四字熟語の語彙を、テンポよく遊びながら学べます。
- 通常モードとリラックスモードの2種類でプレイできます。
- 設定画面で文字の大きさを変更できます。
- アプリ内課金（買い切り）で広告を非表示にできます。

## 社内管理用メモ

### version 1.0.1+2

- Google Play Billing の実装を反映。
- 非消耗型アイテム remove_ads_300 を購入可能にし、購入済み時は広告を非表示化。
- 設定画面から購入復元を実行可能にし、復元済み・未検出・失敗の結果表示に対応。
- 購入状態の起動時同期を追加し、端末再設定後の復元動線を改善。
- Android 側に Billing 権限と Billing Client 依存を反映。
