# 四字熟語・ことわざタップゲーム Spec v1.0

## 1. 概要

Android/iPhone用スマホ用アプリ。
/src/quicktap/配下に作成すること。

### 技術スタック

| 項目 | 内容 |
|------|------|
| フレームワーク | Flutter |
| 言語 | Dart |
| DB | SQLite（`sqflite` パッケージ） |
| 状態管理 | StatefulWidget（シンプルな構成のため） |
| 対応OS | Android / iOS |
四字熟語またはことわざを題材にした1分間のタイムアタック型タップゲーム。  
ランダムにシャッフルされた文字を正しい順番でタップし、語句を完成させる。

## 3. ゲームロジック

### 3.1 問題生成

- DBからランダム取得
- 取得条件：
  - 空文字なし
  - 文字数2以上
- 重複出題防止（1プレイ内）

### 3.2 シャッフル仕様

- Fisher-Yatesアルゴリズム使用
- 完全一致（元と同順）は再シャッフル

### 3.3 入力処理

- タップ順に入力エリアへ追加
- 同一文字は別インスタンス扱い

### 3.4 判定

- 入力文字列 == 正解word → 正解
- 正解時：
  - スコア+1
  - 次問題へ即遷移
- 不正解：
  - 継続（ペナルティなし）

### 3.5 制限時間

- 60秒固定
- 0秒で強制終了 → 結果画面

## 8. エッジケース

- 同一文字複数 → index管理必須
- 1文字語句 → 出題対象外
- DB空 → ゲーム起動不可
- シャッフル不能（全同一文字）→そのまま出題

## 9. パフォーマンス要件

- DBアクセス：初回に全件ロード推奨（数千件想定）
- シャッフル：O(n)
- UI更新：タップごと即時反映
