# 成語並べ（quicktap）Spec v1.2

## 1. 概要

Android/iPhone用スマホアプリ。
実装は `src/quicktap/` 配下。

ランダムにシャッフルされた文字を正しい順番でタップし、語句を完成させる。
プレイモードはタイムアタック（制限時間あり）とリラックス（時間無制限）の2種類。

| フレームワーク | Flutter |
| 言語 | Dart |
| DB | SQLite（`sqflite`） |
| 対応OS | Android / iOS |

---

## 3. ゲームロジック

### 3.1 カテゴリ

| カテゴリ | enum |
|----------|------|
| 四字熟語 | `GameMode.yoji` |
| ことわざ | `GameMode.kotowaza` |

### 3.2 プレイモード

| モード | enum | 内容 |
|--------|------|------|
| タイムアタック | `PlayMode.timeattack` | 制限時間内に正解数を競う |
| リラックス | `PlayMode.relax` | 時間制限なし、終了ボタンで終了 |

### 3.3 制限時間

| カテゴリ | タイムアタック | リラックス |
|----------|----------------|-----------|
| 四字熟語 | 60秒 | なし |
| ことわざ | 180秒 | なし |

### 3.4 問題生成

- DBから該当カテゴリを全件ロード
- 取得条件：
  - `word IS NOT NULL`
  - `word != ''`
  - `length(word) >= 2`
- 選択された `levelFilters` に一致する `level` のみ対象
- 1プレイ内で重複出題を避ける
- 使い切ったら既出管理をリセットして再利用

### 3.5 判定

- 入力文字列 == 正解 `word` で正解
- 正解時：
  - `score +1`
  - ○オーバーレイ表示
  - 語句・読みを短時間表示後、次問題へ
- 不正解時：
  - ×オーバーレイ表示（約700ms）
  - 入力をリセット

### 3.6 スキップ

- 現在問題の語句・読みを表示後、次問題へ
- スコア加算なし

## 5. DB利用仕様（quicktap）

### 使用DB

- `jpword.db`（アセット：`src/quicktap/assets/jpword.db`）
- 起動時に端末ローカルへ配置し、readOnlyで利用

### 起動時DB整合性チェック

以下のいずれかに該当する場合、ローカルDBを削除しアセットDBを再コピーする。

- `yojijukugo` または `kotowaza` に `level` カラムが存在しない
- `kotowaza` に `bunsetsu` カラムが存在しない
- `yojijukugo.level` の非NULL件数が0

### 参照テーブル

- `yojijukugo`（四字熟語）
- `kotowaza`（ことわざ）

### 参照カラム

- `id`, `word`, `reading`, `meaning`, `level`, `bunsetsu`（ことわざのみ）

---

## 6. データ取得SQL

### 四字熟語

```sql
SELECT y.id, y.word, y.reading, y.meaning
FROM yojijukugo y
WHERE y.word IS NOT NULL
  AND y.word != ''
  AND length(y.word) >= 2
  AND y.level IN (?, ...);
```

### ことわざ

```sql
SELECT k.id, k.word, k.reading, k.meaning, k.bunsetsu
FROM kotowaza k
WHERE k.word IS NOT NULL
  AND k.word != ''
  AND length(k.word) >= 2
  AND k.level IN (?, ...);
```

※ `levelFilters` 未指定時は `AND ... level IN` 句なし。

## 8. エッジケース

- 同一文字複数：インデックスで識別
- 1文字語句：出題対象外
- DB空：問題生成不可
- 全文字同一でシャッフル不可：最大試行後に同順許容

## 10. 広告仕様（AdMob）

### 10.1 目的

- 無料アプリ運用のため、ゲーム画面にバナー広告を表示する。

### 10.2 広告ネットワーク

- Google AdMob（`google_mobile_ads`）

### 10.3 利用ID（本番）

| 種別 | 値 |
|------|------|
| AdMobアプリID | `ca-app-pub-4954876478259153~3499751135` |
| バナー広告ユニットID | `ca-app-pub-4954876478259153/4155796641` |

### 10.4 プラットフォーム設定

- Android
  - `AndroidManifest.xml` の `com.google.android.gms.ads.APPLICATION_ID` にアプリIDを設定
- iOS
  - `Info.plist` の `GADApplicationIdentifier` にアプリIDを設定

### 10.5 表示仕様

- 表示画面：ゲーム画面（`GameScreen`）
- 位置：画面下部
- フォーマット：Banner（`AdSize.banner`）
- 表示条件：広告読込成功時のみ表示（失敗時は非表示でゲーム進行を継続）

### 10.6 失敗時挙動

- 広告ロード失敗時は広告オブジェクトを破棄し、再試行は行わない。
- 広告が表示できない場合でも、ゲーム機能（出題・判定・遷移）は継続する。
